افزونه پرتال دانش‌آموز و مشاور راه کنکور با معماری مستقل REST API برای وب‌سایت وردپرس و اپلیکیشن موبایل آینده.

== Description ==

افزونه RK Student Portal طبق استانداردهای دقیق معماری راه کنکور طراحی شده است:
* ۱۰۰٪ مستقل از قالب و بدون دستکاری در کدهای قالب.
* بدون نیاز به ACF، بدون CPT UI، بدون فرم‌ساز — کاملاً بهینه و کدنویسی بومی.
* دیتابیس اختصاصی با ۷ جدول پرسرعت توسط dbDelta.
* اندپوینت‌های استاندارد REST API تحت نیم‌اسپیس `rksp/v1`.
* احراز هویت بدون نیاز به پلاگین‌های جانبی با توکن‌های امن و قابل ابطال در هدر `Authorization: Bearer <token>`.
* سیستم باشگاه ساعت مطالعه با ۵ دقیقه Transient Cache.
* باشگاه پیشرفت خودکار با محاسبات کرون جاب روزانه (ساعت ۰۰:۰۵).
* کاملاً بومی برای وردپرس: ساخت خودکار برگه‌ها، پشتیبانی کامل از ویرایشگر گوتنبرگ (بلاک ادیتور) و شورتکدهای استاندارد بدون نیاز به المنتور یا هیچ صفحه‌ساز جانبی.

== Installation ==

۱. فایل فشرده `rk-student-portal.zip` را دانلود کنید.
۲. در پیشخوان وردپرس به مسیر **افزونه‌ها > افزودن > بارگذاری افزونه** بروید.
۳. فایل زیپ را انتخاب کرده و بر روی **نصب** و سپس **فعال‌سازی** کلیک کنید.
۴. در لحظه فعال‌سازی، جداول اختصاصی پایگاه داده و ۴ برگه استاندارد وردپرس به صورت کاملاً خودکار ایجاد می‌شوند:
   * برگه پرتال دانش‌آموز (`/student-portal/`)
   * برگه پرتال مشاور (`/mentor-portal/`)
   * برگه باشگاه ساعت مطالعه (`/study-leaderboard/`)
   * برگه باشگاه پیشرفت (`/study-achievements/`)
۵. بدون نیاز به هیچ صفحه‌سازی، می‌توانید مستقیماً از این برگه‌ها استفاده کرده یا در ویرایشگر گوتنبرگ بلاک‌های اختصاصی پرتال را در هر نقطه‌ای از سایت قرار دهید.

== Gutenberg Blocks ==

* `rksp/student-portal` : بلاک پرتال جامع دانش‌آموز
* `rksp/mentor-portal` : بلاک پرتال مشاور تحصیلی
* `rksp/leaderboard` : بلاک جدول باشگاه ساعت مطالعه
* `rksp/achievements` : بلاک فید باشگاه پیشرفت و افتخارات

== Shortcodes ==

* `[rksp_student_portal]` : پرتال دانش‌آموز
* `[rksp_mentor_portal]` : پرتال مشاور
* `[rksp_leaderboard period="weekly"]` : جدول رتبه‌بندی مطالعه
* `[rksp_achievements]` : فید دستاوردهای باشگاه پیشرفت

== Database Tables ==

* `wp_rksp_assignments` : انتساب مشاور به دانش‌آموز همراه با تاریخچه
* `wp_rksp_study_logs` : ثبت لاگ ساعت مطالعه با ایندکس‌های بهینه
* `wp_rksp_tasks` : گزارش کارها و تکالیف دانش‌آموز
* `wp_rksp_notes` : نظرات عملکرد تحصیلی ثبت‌شده توسط مشاور
* `wp_rksp_plans` : اشتراک و طرح‌های تحصیلی با تاریخ انقضا
* `wp_rksp_achievements` : افتخارات و دستاوردهای خودکار باشگاه پیشرفت
* `wp_rksp_tokens` : توکن‌های ایمن API اپلیکیشن موبایل با قابلیت لغو
